## Runtime composition and private static-library relinking

preparation, schema-2 install-time Runtime composition and an explicit private

and dependency pins are unchanged. These mechanisms do **not** approve R1/R2.

bytes, both embedded font identities and the generated icon-definition family.
It emits license-only excerpts, including Font Awesome/ProggyClean, StrHash64,
