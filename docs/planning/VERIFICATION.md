## Isolated allocator arithmetic proof

Pinned evidence: [`src/sys/ml.c:11–17`](https://github.com/ethteck/pokemonsnap/blob/df8815e75f3d79618466e01e0827c6165b93d11c/src/sys/ml.c#L11-L17).

An isolated temporary C fixture was compiled and executed with:

```sh
cc -std=c11 -Wall -Wextra -Werror <temporary allocator-smoke.c> -o <temporary allocator-smoke> && <temporary allocator-smoke>
```

The recorded exit code was **0**, with **64-bit pointers** on this LP64 host. Synthetic arithmetic produced `synthetic_legacy=56780010` versus `synthetic_widened=123456780010`: the legacy 32-bit complement mask loses the upper address bits. An actual high-address `malloc` allocation exercised the same loss and passed the fixture assertions. Real allocation addresses are deliberately omitted; the displayed addresses are synthetic, not ASLR observations. The fixture source and executable were removed afterward.

This proves the isolated complement-mask hazard. It neither compiles the original translation unit nor validates an allocator integration, a native game, or another platform.
